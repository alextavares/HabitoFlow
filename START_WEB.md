# 🌐 HabitoFlow - Rodando no Navegador

## ✅ O app está rodando!

O servidor webpack foi iniciado com sucesso. Para acessar o app:

### 📱 Acesse no navegador:
```
http://localhost:8080
```

### 🎯 O que você verá:
1. **Tela de Login** com Firebase
2. **Opções de login**:
   - Email/senha
   - Google Sign-in
   - Criar nova conta

### 🔥 Funcionalidades disponíveis:
- ✅ Login/Cadastro com Firebase
- ✅ Dark Mode
- ✅ Navegação por tabs
- ✅ Adicionar/editar hábitos
- ✅ Visualizar estatísticas
- ✅ Sistema de conquistas
- ✅ Animações (confetti, checkbox)

### ⚠️ Limitações da versão web:
- Push notifications não funcionam
- Algumas animações nativas podem ser diferentes
- Google Sign-in pode precisar de configuração adicional

### 🛠️ Comandos úteis:
```bash
# Parar o servidor: Ctrl+C

# Rodar novamente:
npm run web

# Build para produção:
npm run web:build
```
