# Material para Play Store - HabitoFlow

## 📱 Screenshots Necessários

### Requisitos da Play Store
- Mínimo 2 screenshots
- Máximo 8 screenshots por tipo de dispositivo
- Formatos: JPEG ou PNG (24-bit, sem alpha)
- Dimensões recomendadas:
  - **Telefone**: 1080 x 1920 (16:9)
  - **Tablet 7"**: 1200 x 1920
  - **Tablet 10"**: 1600 x 2560

### Screenshots Sugeridos

1. **Tela de Login** - Primeira impressão do app
   - Mostrar o design clean e moderno
   - Destacar login social (Google)

2. **Tela Principal (Hábitos)** - Funcionalidade principal
   - Lista de hábitos coloridos
   - Mostrar diferentes estados (completado/pendente)
   - Streak visível

3. **Adicionar Hábito** - Facilidade de uso
   - Modal de criação
   - Seleção de ícones e cores
   - Configuração de lembretes

4. **Estatísticas** - Progresso visual
   - Gráficos semanais
   - Cards de resumo
   - Percentuais de conclusão

5. **Conquistas** - Gamificação
   - Lista de conquistas desbloqueadas
   - Sistema de níveis
   - Pontuação

6. **Perfil** - Personalização
   - Tema escuro/claro
   - Configurações
   - Informações do usuário

### Como Capturar Screenshots

#### No Emulador Android Studio:
1. Abra o app no emulador
2. Configure para modo retrato
3. Use o botão de câmera no painel do emulador
4. Salve em alta qualidade

#### No Dispositivo Real:
1. Power + Volume Down simultaneamente
2. Ou use o modo desenvolvedor com `adb shell screencap`
